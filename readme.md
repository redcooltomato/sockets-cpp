## pretty basic server-client tcp messager
all users name themselves and connect to one chat. <br>
not thread safe (◎‿○)


messages are essentially plaintext. it's impossible to impressonate others, as authoring is controlled by the server, tho names get cleared after their owned disconnects.





###  note for self: code style

- normal variable names are lowerCamelCase
- function names folow snake_case
- constants/define flags use CAPITALIZED_SNAKE
